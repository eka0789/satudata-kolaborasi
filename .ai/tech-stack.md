# Official Technology Stack

## Core Ecosystem & Monorepo
- **Package Manager**: `pnpm` (Fast, disk space-efficient package manager)
- **Monorepo Manager**: `Turborepo` (High-performance build system for JavaScript/TypeScript monorepos)

## Frontend Stack
- **Framework**: `React 18+`
- **Language**: `TypeScript` (Strict mode)
- **Build Tool**: `Vite`
- **Routing**: `React Router v6+`
- **Styling**: `Tailwind CSS v3+`
- **UI Components**: `shadcn/ui` + `Radix UI` primitives
- **Icons**: `Lucide Icons`
- **State & Data Fetching**: `TanStack Query v5` (React Query)
- **Form Management**: `React Hook Form`
- **Validation**: `Zod`

## Backend Stack
- **Framework**: `Hono` (Ultrafast web framework for Edge / Node.js)
- **Language**: `TypeScript` (Strict mode)
- **Runtime**: `Node.js` / `Cloudflare Workers` / `Vercel Serverless`

## Database & Authentication
- **Database Engine**: `Supabase PostgreSQL`
- **ORM**: `Drizzle ORM` (Type-safe SQL ORM)
- **Authentication**: `Supabase Auth` (JWT, RBAC, Session Management)
- **Object Storage**: `Supabase Storage` (Arsip Surat, Lampiran Dokumen)

## Deployment & CI/CD
- **Hosting**: `Vercel` / Enterprise Docker Container
- **Database Hosting**: `Supabase`

## Testing & Quality Assurance
- **Unit & Integration Testing**: `Vitest`
- **End-to-End Testing**: `Playwright`
- **Linter**: `ESLint`
- **Formatter**: `Prettier`
